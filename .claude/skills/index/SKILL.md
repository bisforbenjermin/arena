Regenerate the canon index. Enumerate only: no judgment, no summaries of what a ruling says. The index is pointers; the ruling files are truth (OPS-5 rule 5).

1. `pwd` must end in `code/arena`, or, in a cloud session, `git remote get-url origin` must name `bisforbenjermin/arena`. If not, stop. `git pull --rebase`.
2. Write `governance/10-CANON/DECISIONS/INDEX.md` from the files on disk:

   **Header line.** `Generated by /index on <YYYY-MM-DD> from <N> rulings, <M> proposals, <K> superseded files. Regenerate with /index; never hand-edit. Pointers only — the ruling files are truth.`

   **Table 1 — Rulings.** Every `*.md` in `governance/10-CANON/DECISIONS/` except `INDEX.md`, sorted by id, one row each: id · title (line 1 after the dash) · Ruled date · Reversibility · Confidence · Ratified (the date after `Ratified by founder`, or `pending`, or `— missing`) · Downstream (first 80 characters of the first line under `## Downstream`, or `— empty`) · file.

   **Table 2 — Proposed.** Every `*.md` in `governance/00-COMMAND/PROPOSED/` except `*.critique*.md`: id · title · its `Status:` line · Reversibility · file. A proposal with no `Status:` line gets `— missing`.

   **Table 3 — Superseded.** Every file under `governance/90-ARCHIVE/` whose first five lines contain `SUPERSEDED BY` or `Supersedes:`: file · superseded by / supersedes · date folder.

   A field you can't parse gets `— unparsed`. Never guess it.
3. Commit on main: `git add governance/10-CANON/DECISIONS/INDEX.md`, `git commit -m "docs: canon index <YYYY-MM-DD>"`, push. On any other branch, write the file but don't commit, and say so.
4. Reply with three lines: the counts, then every cell that reads `— missing`, `— empty` or `— unparsed` with its file (or "none"), then `Fixes are the founder's: /rule to supersede, never an edit (OPS-2).`
